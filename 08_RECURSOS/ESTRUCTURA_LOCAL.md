# Organización de descargas (local)

```
assets-inbox/             # ZIP originales y licencia, no commitear por defecto
assets-source/            # fuentes Blender/FBX permitidas
public/assets/            # solo derivados y originales con permiso web
  branding/
  models/
  sprites/
  textures/
  effects/
ASSETS.md                 # créditos y licencia por archivo
```

`08_RECURSOS/brand/` es el kit de marca de esta fase. Cuando exista la app, mover los SVG a `public/assets/branding/` y mantener la ficha de licencia; no duplicar el logo en varias carpetas.

Descargar manualmente desde URLs de `assets.csv`, guardar fecha y licencia original, descomprimir sin ejecutar scripts, inspeccionar formatos y tamaño, y copiar solo lo necesario. Convertir con Blender si hace falta. No confundir un enlace de ficha con una URL de descarga automatizada. No se incluye script que eluda cuentas o formularios. Si un enlace cambia, buscar la fuente oficial y anotar nueva URL.
